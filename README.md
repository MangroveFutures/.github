# MangroveFutures/.github

The org's shared defaults: issue forms, the pull-request template and shared workflows. GitHub applies
these to every MangroveFutures repo that has no version of its own.

- **Public on purpose.** GitHub requires this repo to be public for the defaults to work. Nothing
  proprietary or secret belongs here. Every other repo, and every issue in them, stays private.
- **Never edit this repo by hand.** It is copied automatically from `org-dotgithub/` in
  `MangroveFutures/home` (private). Change the files there.
- **The full explanation:** `handbook/reference/the-dotgithub-repo.md` in `MangroveFutures/home`.
